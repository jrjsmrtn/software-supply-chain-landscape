# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Reporting

Report unacceptable behaviour to the maintainer: **<jrjsmrtn@gmail.com>**. Reports are handled
confidentially.

## A note specific to this project

This bundle documents specifications, tools and regulations — including ones its maintainer finds
poorly designed, and ones with active commercial partisans. **Recording what an instrument says
accurately is not endorsing it, and disliking a format is not a reason to describe it inaccurately.**

Advocacy for or against a particular tool, format or vendor belongs in that project's own venue.
Contributions showing that a concept **misstates** something are the most valuable thing here — see
[CONTRIBUTING.md](CONTRIBUTING.md).
