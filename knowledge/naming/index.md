# Component identifiers

* [purl (Package URL)](purl.md) - The canonical identifier for a software package, derived from where the artifact came from.
* [purl type definitions](purl-type-definitions.md) - The per-type registry that constrains everything after `pkg:`.
* [Provisional identifiers for unregistered purl types](provisional-purl-identifiers.md) - What to emit when an ecosystem has no registered type yet.
* [CPE](cpe.md) - The older identifier, naming IT products rather than packages.
* [BOM-Link](bom-link.md) - A URN referencing another BOM, or one component inside it.

# Vulnerability identifier namespaces

* [CVE](cve.md) - The shared vulnerability namespace everyone cites.
* [GHSA](ghsa.md) - GitHub Advisory Database identifiers, often issued before a CVE exists.
* [OSV IDs](osv-ids.md) - Per-source ecosystem advisory identifiers, aggregated by osv.dev.
